# Woohoo Studio：AI 多智能体短剧创作工作台

## 作品简介

Woohoo Studio 是一个面向短剧、短视频和创意内容团队的 AI 多智能体创作工作台。它把「创意对话」「多智能体分工」「制作流水线」「AI 图片生成」「资产管理」「工程导出」放进同一个工作区，帮助创作者从一句想法快速推进到可交付的策划包和素材资产。

## 解决的问题

短剧创作通常会在多个工具之间来回切换：聊天工具里想创意，文档里写大纲和剧本，表格里管分镜，网盘里堆素材，最后再手动整理交付包。这个过程容易丢上下文、丢版本，也很难让不同角色的意见形成结构化产出。

Woohoo Studio 的目标是把创作链路收束成一条可运行的产线：先让 AI 智能体协同讨论，再把成熟方案推进到制作流程，最后沉淀为可复用资产和可导出的项目包。

## 核心功能

- 多智能体创意对话：内置大纲架构师、人设生成专家、分镜渲染师、合规审核官、主编统筹官、项目管理官。
- 协同会话：支持任务分派、回复队列、循环检测、入工作区判定和 SSE 实时事件。
- 制作流水线：覆盖大纲、剧本、章节、角色场景、关键帧、视频等阶段。
- AI 图片生成：支持图片生成任务、模型/尺寸配置、积分计费和生成资产入库。
- 资产库：统一管理图片、视频、音频、文档等项目资产。
- 服务端任务监控：通过真实后端任务和 SSE 展示排队、执行、完成、失败等状态。
- 导出交付：支持导出完整项目工程包和核心策划包。

## 技术实现

- 前端：React 18 + TypeScript + Vite 5
- UI：Arco Design + Lucide Icons
- 状态管理：Zustand
- 后端：Rust + Axum + Tokio
- 数据库：SQLite + sqlx
- 鉴权：JWT + bcrypt
- 部署：Docker Compose，Nginx 反向代理前端和后端

## Demo 演示路径

1. 登录 Woohoo Studio。
2. 在「创意对话」输入短剧创意，触发 AI 回复。
3. 查看多智能体列表，展示不同角色如何参与创作。
4. 进入「制作流程」，展示从创意到剧本、分镜、关键帧、视频的产线。
5. 进入「图片生成」，展示视觉资产生成入口。
6. 进入「资产库」，展示项目资产沉淀。
7. 打开「预览视图」，展示服务端任务状态监控。
8. 使用右上角导出菜单，导出完整工程包或核心策划包。
