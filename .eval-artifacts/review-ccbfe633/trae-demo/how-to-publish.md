# TRAE 初赛 Demo 发布步骤

参考帖子：https://forum.trae.cn/t/topic/22549

## 发布前检查

- 已通过报名审核。
- Demo 与报名创意方向一致。
- Demo 可以体验：公开体验链接、HTML Zip 附件、源码/部署链接三选一。
- 至少 3 张关键步骤截图。
- 至少 3 个 TRAE Session ID。
- 通过的报名帖链接。

## 发帖入口

进入 TRAE 官方中文社区的「大赛初赛专区」发新帖。

## 发帖设置

- 分类：`TRAE AI 创造力大赛 / 大赛初赛专区`
- 标签：`学习工作`
- 标题：`〖学习工作赛道〗Woohoo Studio：AI 多智能体短剧创作工作台 Demo`

## 正文结构

复制 `trae-demo/submission-post.md`，再替换以下内容：

- `体验/源码附件链接`
- 3 个以上 Session ID
- 3 张以上截图
- 通过审核的报名帖链接

## 附件建议

社区只支持文字、图片、GIF、链接和 20M 以内文件。优先贴 GitHub 分支链接：

```text
https://github.com/lllllxxxxx111/woohoo/tree/codex/agent-eval-good-features
```

也可以附加当前提交包：

```text
woohoo-studio-trae-demo-20260703.zip
```

大小不到 1 MB，可以直接尝试上传；如果论坛附件上传失败，再放到 GitHub 或飞书云文档并贴公开链接。
